# 고객군별 개별 품목 예측 실험

2026-09-16. 고객 전체 주문 빈도로 고객군을 정하고, 각 고객×상품의 다음 구매일과 수량은 개별 이력으로 예측했다. 고객군별 모델 분리와 전체 이력 확대만으로는 이번 개발 평가에서 날짜 적중률이 크게 개선되지 않았다. 앱에 적용한 변경은 없다.

## 예측 단위와 고객군

고객군은 고객이 모든 상품에 걸쳐 구매한 서로 다른 날짜의 간격으로 정한다. 같은 날 여러 상품을 사면 고객 주문일은 1회다. 각 상품의 구매일·수량·간격은 기존 고객×상품 피처로 별도 유지한다. 매주 주문하는 고객도 원두는 매주, 시럽은 매달로 서로 다르게 예측할 수 있다. 고객 ID는 모델 피처에 넣지 않지만, ID로 각 고객의 과거 이력을 추적한다. 고객군별로 학습된 공통 함수를 각 고객×상품에 적용하며, 고객마다 모델 파일을 하나씩 만드는 방식은 아니다.

예측 시점까지의 고객 주문 간격이 3개 미만이면 이력 부족으로 분류한다. 나머지는 최근 최대 5개 간격의 중앙값으로 14일 이하, 14일 초과~30일 이하, 30일 초과~60일 이하, 60일 초과로 나눈다. 같은 최근 간격들의 표준편차/평균이 0.75보다 크면 불규칙군을 우선 적용한다. 보류 상품이 있는 날짜에는 고객군 계산용 이력을 보수적으로 초기화한다. 같은 날짜의 정상 상품은 그 뒤 한 주문일로 반영한다. 고객군은 매 구매일 갱신하며 미래 재구매일로 정하지 않는다.

군별 학습 사례가 300건 이상일 때만 해당 군의 수량·주기 XGBoost를 따로 학습한다. 이력 부족군과 표본 부족군은 전체 모델을 사용한다. 이 실험은 같은 알고리즘을 각 군의 자료로 따로 학습하는 첫 비교이며, 군마다 서로 다른 알고리즘을 탐색한 결과는 아니다.

## 동일 조건의 실제 데이터 비교

구매 기준일은 2026-04-01~04-30, 05-01~05-31, 06-01~06-16의 세 구간이다. 학습 마감일은 각각 03-31, 04-30, 05-31이다. 모든 예측 대상을 90일 관찰하며 마지막 관찰일은 09-14다. 마지막 수집일인 09-15의 완결 여부가 미확정이라 사용하지 않는다. 한 사례는 고객×상품의 구매일 한 건이며, 같은 고객×상품이 여러 날짜에 반복해서 등장할 수 있다. 예측 대상 15,491건 중 90일 내 재구매 7,551건에서 날짜·수량 오차를 계산했다. 7,934건은 90일 내 재구매가 없고, 6건은 보류로 결과를 알 수 없다.

270일 제한은 학습 마감일에서 269일 전 이후의 구매 기준일만 사용한다는 뜻이다. 두 조건 모두 기준일부터 90일 관찰이 끝난 학습 사례 중 90일 내 재구매한 건만 학습한다. 따라서 학습 마감 직전 90일의 구매 기준일은 학습에 들어가지 않는다. 전체 이력 조건은 이 시작일 제한을 해제하여 최초 유효 구매일인 2024-10-16부터 사용한다. 두 조건 모두 개인 피처는 해당 예측 시점까지의 전체 유효 이력으로 만든다.

수량·주기 모델 모두 absolute-error 목적함수, 깊이 4, 200회 학습 및 같은 XGBoost 설정을 사용한다. 날짜·수량 예측은 최소 1로 제한하고 반올림한다. 고객군 경계와 설정은 각 실행 전에 고정했다.

학습 마감일에 모델을 고정한 뒤, 각 예측 기준일의 피처와 고객군은 그 구매일까지의 이력으로 갱신한다. 피처까지 학습 마감일에 동결한 것이 아니다. 예측 시점은 기준 구매일 다음 날 0시다.

| 학습 범위 / 방식 | 주기 ±7일 | 주기 ±14일 | 날짜 MAE | 고객별 동일 가중 MAE | 수량 ±2개 |
|---|---:|---:|---:|---:|---:|
| 270일 제한 / 전체 모델 | 40.8% | 65.3% | 13.77일 | 16.98일 | 97.7% |
| 270일 제한 / 고객군별 모델 | 40.2% | 65.1% | 13.91일 | 16.95일 | 97.5% |
| 전체 이력 / 전체 모델 | 41.1% | 64.9% | 13.70일 | 16.83일 | 97.9% |
| 전체 이력 / 고객군별 모델 | 40.8% | 64.7% | 13.81일 | 16.73일 | 97.6% |

주평가지표는 고객마다 같은 가중치를 주는 날짜 MAE다. 세 평가 구간의 관측된 재구매 사례를 모아 고객별 평균 절대 오차를 구한 뒤 고객 간 평균을 계산한다. 군별 분리로 이 지표는 270일 조건에서 0.03일, 전체 이력 조건에서 0.10일 개선됐지만, 사건별 MAE와 ±7일 적중률은 악화됐다. 따라서 뚜렷한 개선으로 판단하지 않는다. 전체 이력의 전체 모델은 270일 전체 모델보다 ±7일 적중률이 약 0.26%p 높다. 이 역시 큰 개선으로 해석하지 않는다.

위 표는 고객군별 모델을 분리하는 방식의 전체 성능 비교다. 특정 군이 모두 같은 영향을 받았다는 뜻은 아니다. 군별 건수와 점수는 [270일 집계](cadence-groups-v1.json)와 [전체 이력 집계](cadence-groups-full-v1.json)의 `real.*.groups`에 보존한다.

90일 내 재구매가 없던 7,934건에도 네 후보 모두 90일 이내 날짜를 출력했다. 따라서 위 적중률은 전체 고객에 대한 자동 장바구니 성공률이 아니다. 재구매 여부를 판단하거나 추천을 보류하는 기능은 이번 날짜·수량 회귀 모델에 없다.

이전에 보고한 최근 이력 모델의 73%는 08-14 전에 다음 구매가 확인된 1,196건을 평가한 값이다. 재구매 간격 중앙값은 11일이었다. 마감 이후에 재구매한 별도 1,392건의 중앙값은 26일이었다. 현재 표는 모든 대상에 90일을 부여하며 학습 설정도 다르므로 73%와 직접 비교하지 않는다. 기존 60일 관찰 실험과도 구간·관찰 길이가 달라 직접 순위를 매기지 않는다.

## 더미 데이터 진단

각 시나리오 200건, 총 2,200개의 인공 고객×상품 다음 구매 사례를 생성했다. 시드 20260916, 구매 기준일 08-15, 과거 이력 시작은 04-09다. 실제 고객 기록을 복제하거나 모델 예측값을 정답으로 삼지 않았다. 정답은 별도 구매 규칙으로 생성하고, 미래 정답은 피처 생성에 넣지 않았다. 표준 시나리오의 간격에는 ±2일, 수량에는 ±1개 변동을 주었다. 대부분 단일 상품 매장이며 한 시나리오만 매주 사는 다른 상품을 추가했다. 상품 식별자는 기존 학습에서 가장 많이 관측된 두 상품을 사용했다.

원본 최근 이력 모델과 270일 조건의 06월용 전체·고객군별 모델을 같은 인공 입력에 적용했다. 원본 모델은 07-13까지, 나머지는 05-31까지 학습했다. 전체 이력 학습 모델의 인공 재평가는 이번 표에 포함하지 않는다. 인공 상품 전체 통계, 과거 길이와 수량 분포는 실제 데이터와 다르므로 이 표는 이상 행동 진단이며 실제 고객 적중률이나 모델 순위의 증거가 아니다.

| 인공 구매 패턴 | 기존 최근 모델 ±7일 | 270일 범위·90일 관찰 전체 모델 ±7일 | 같은 조건 고객군별 ±7일 |
|---|---:|---:|---:|
| 매주 | 100.0% | 92.5% | 100.0% |
| 2주마다 | 53.5% | 87.0% | 70.0% |
| 매달 | 0.0% | 98.5% | 71.5% |
| 45일마다 | 0.0% | 100.0% | 100.0% |
| 75일마다 | 0.0% | 0.0% | 0.0% |
| 불규칙 4·10·25·50·75일 | 42.0% | 15.5% | 18.5% |
| 갑자기 14일→4~7일 | 100.0% | 0.0% | 1.5% |
| 수량 갑자기 4배 | 57.0% | 84.0% | 74.0% |
| 첫 구매만 있음 | 30.5% | 17.5% | 17.5% |
| 매주 주문하는 매장의 월간 품목 | 0.0% | 100.0% | 100.0% |

월간 품목/주간 매장 시나리오에서 예측 주기의 중앙값은 원본 최근 모델 7일, 90일 학습 전체 모델 30일, 고객군별 모델 28일이다. 개별 상품 주기는 별도 보존된다. 75일 구매의 과거 간격은 짧은 인공 관찰 구간 때문에 충분하지 않아 이력 부족군에 속하며, 이 결과로 충분한 이력을 가진 모든 장기 고객을 평가했다고 볼 수 없다.

수량이 갑자기 4배가 되는 시나리오에서 수량 ±2개 적중률은 원본 5.5%, 전체 모델 4.5%, 고객군별 2.5%다. 모델에 수요 급증의 사전 단서는 주지 않았다. 표의 10개 시나리오 2,000건 외에 재구매가 60일 동안 없는 200건을 별도 진단했다. 이 200건에는 세 모델 모두 60일 안의 구매일을 출력했다. 인공 미구매 시나리오의 60일과 실제 평가의 90일은 별도 정의다.

## 해석과 다음 실험

현재 고객군 구분은 개별 상품 이력을 대체하지 않는다. 다만 군별로 학습 자료를 분리하는 것만으로는 실제 날짜 예측이 뚜렷하게 개선되지 않았다. 다음 비교에서는 고객 주문 주기와 품목 주기를 전역 모델의 별도 피처로 함께 제공하거나, 개인 품목의 과거 주기를 기준으로 보정하는 방법을 같은 평가 대상에서 확인할 수 있다. 이 제안의 성능은 아직 측정하지 않았다. 90일보다 긴 구매 주기는 더 긴 동일 관찰 기간으로 별도 검증해야 한다.

## 재현과 한계

이 결과는 이미 사용한 역사 구간을 재사용한 개발 평가다. 새로운 최종 시험이 아니며, 수집 당시 최종 주문 상태가 과거 예측 시점에도 알려졌는지는 미검증이다. 전체 이력 확대는 270일 결과를 확인한 뒤 사용자가 요청하여 실행했다. 임의로 설정을 반복 탐색한 뒤 최종 시험 성능으로 보고하지 않는다.

다음 명령은 기존 산출물 폴더가 없는 별도 작업 복사본에서 실행한다. 현재 작업 폴더에서는 저장된 보고서를 열어 확인하며 기존 결과를 삭제하거나 덮어쓰지 않는다.

```bash
.venv/bin/python -m scripts.run_cadence_groups
.venv/bin/python -m scripts.evaluate_cadence_synthetic
.venv/bin/python -m scripts.run_cadence_groups --config config/cadence-groups-full-v1.json --output artifacts/cadence-groups-full-v1
.venv/bin/python -m scripts.verify_cadence_groups
.venv/bin/python -m unittest discover -s tests
```

기존 출력 폴더 덮어쓰기는 금지한다. 재현하려면 별도 작업 복사본 또는 새 출력 경로를 사용해야 하며, 인공 비교·검증 스크립트는 위 기본 경로를 읽는다. 실행 설정과 모델, 예측값은 `artifacts/cadence-groups-v1`, `artifacts/cadence-groups-full-v1`에 저장된다. 최초 270일 실행 코드 원문은 첫 폴더의 `run_cadence_groups.source.py`에 보존했다. 이후 실행 경로 인자만 추가했다.

두 실행의 저장 모델을 재로드해 총 61,964개의 실제 평가 예측을 재현하고 pandas로 주요 지표를 독립 재집계했다. [검증 결과](cadence-verification.json). 인공 비교 6,600개 예측의 허용 오차 집계도 pandas로 대조했다. 자동 테스트 60개가 통과했다. 고객 단위 기술적 부트스트랩은 개발 구간 내 변동성 설명용이며 새 최종 시험이나 모델 선택을 보정한 검정이 아니다.
