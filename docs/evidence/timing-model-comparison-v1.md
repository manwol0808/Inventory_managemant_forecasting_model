# 주기·재구매 확률·TabPFN 비교 결과

2026-09-16 실행 완료. 주기 우선 32구성, 생존분석 14후보, TabPFN와 동일 표본 XGBoost 2후보를 각각 세 과거 구간에서 비교했다. 운영 모델로 교체하지 않았다.

**날짜 MAE는 줄었지만 ±7일 적중률은 약 48%에 머문다. 재구매 확률 모델도 자동 장바구니에 적용하기에는 놓치는 구매가 많다.** 최신 모델을 적용하면 주기를 모두 맞출 수 있다는 결과는 아니다.

## 같은 평가 대상

원본은 2024-10-02~2026-09-15의 138,427행이며 정제·격리 후 식별 가능한 이력으로 피처를 만들었다. 이번 평가의 출발 구매는 **2026-04-01~06-30**이며 각 구매 이후 60일을 관찰했다. 이는 이전 8~9월 최종 시험과 기간·관찰 조건이 다르므로, 이전 날짜 MAE 약 5일과 아래 약 10일을 직접 비교하지 않는다.

|출발 구매월|전체 출발 구매|60일 내 재구매|60일 미구매|보류로 불명|
|---|---:|---:|---:|---:|
|4월|6,796|2,942|3,851|3|
|5월|5,698|2,446|3,251|1|
|6월|5,642|2,494|3,146|2|
|합계|18,136|7,882|10,248|6|

날짜·수량 오차는 재구매 7,882건, 해당 고객 1,449명에 한정한다. 60일 미구매는 영구 이탈이나 재고가 남았다는 뜻이 아니다. 다른 판매처 구매도 관측하지 않는다.

## 날짜와 수량

|후보|날짜 MAE|고객 평균 날짜 MAE|날짜 ±7일|수량 ±1개|수량 ±2개|
|---|---:|---:|---:|---:|---:|
|개인 주기 중앙값·직전 수량|12.64일|15.79일|48.12%|90.21%|96.87%|
|XGBoost, 학습 창의 전체 관측 재구매 사례|10.10일|11.68일|47.59%|90.90%|97.17%|
|TabPFN v2, 1,000개 사례|10.13일|11.83일|47.96%|90.90%|97.17%|
|XGBoost, 동일한 1,000개 사례|10.37일|12.22일|47.31%|90.90%|97.17%|

XGBoost 전체 사례 후보는 `w180_abs_d4_200_qmedian_last3`다. 각 월에 8,842/9,886/10,499개 사례로 학습했다. 고객 평균 날짜 MAE와 수량 ±1개 조건으로 32구성 중 선택했다. 전체 MAE가 줄어도 ±7일 적중률은 개인 주기 기준보다 약간 낮다. 평균 오차 개선을 날짜 적중률 개선으로 설명하지 않는다.

AI 후보 세 개의 수량은 모두 **최근 3번 주문 수량의 중앙값**이다. 수량을 별도 AI로 다시 학습한 점수가 아니므로 같은 수량 적중률이 나온다. 1~2개 주문에서 2개 차이는 클 수 있어 작은 수량 집단과 과다/과소 오류도 JSON 보고서에 보존했다.

선택 XGBoost와 TabPFN은 60일 미구매 10,248건에도 모두 60일 이내의 날짜를 제시했다. 재구매한 사람만 학습한 날짜 회귀를 전체 고객에게 바로 적용하면 불필요한 추천이 생길 수 있다는 뜻이다. 이 비율은 실제 장바구니 조작 결과가 아니다.

## 재구매 확률

생존분석은 재구매 기록과 관측 종료까지 재구매하지 않은 기록을 함께 학습한다. 선택 후보는 `w90_normal_s1_d2`다. 주간 시점 110,984건, 실제 다음 7일 구매 양성 7,711건, 고객 2,900명이 평가에 포함됐다. 같은 출발 구매가 여러 주차에 포함될 수 있다.

고객 평균 Brier는 같은 학습 창의 단순 KM 기준 **0.08474 → 0.07781**, 약 8.2% 감소했다. 확률의 제곱 오차이며 낮을수록 좋다. 60일 구매 여부 Brier는 0.25165 → 0.15370이다. 고객 단위 재표집 구간은 검증 JSON에 있으나 후보 선택 편향·시간 변화를 보정한 운영 신뢰구간은 아니다.

|추천 확률 문턱|추천 중 실제 7일 구매 비율|실제 7일 구매 중 추천 비율|전체 평가 기회 중 추천|
|---|---:|---:|---:|
|20%|34.75%|30.83%|6.16%|
|35%|52.45%|8.61%|1.14%|
|50%|59.66%|0.92%|0.11%|

문턱을 높이면 추천의 정밀도가 높아지지만 대부분의 실제 구매를 놓친다. 이 문턱은 미리 정한 진단값이며 운영 기준으로 채택하지 않았다. 같은 구매의 반복 추천을 제거한 앱 동작 검증도 아니다.

AFT의 무조건부 중앙 날짜는 관측 재구매에서 MAE 35.28일로, 날짜 회귀를 대체할 수준이 아니다. 60일 검열 뒤의 긴 날짜는 검증되지 않은 외삽이다. 이번 생존분석에서는 KM 기준보다 확률 예측의 제곱오차가 줄었으며, 순위 구분력 자체의 개선이나 날짜 예측 우승을 뜻하지 않는다. KM의 61일 표시는 60일 내 중앙값 미도달 표시이므로 정확한 날짜로 해석하지 않는다.

## TabPFN의 범위와 실행 환경

이번에 실행한 모델은 **TabPFN v2**다. 최신 v3.5 공개 가중치는 비상업용으로 안내되므로 실행하지 않았다. v2는 추가 출처 표시 조건이 있는 Prior Labs License이며, 공식 모델·라이선스 파일을 로컬에 보존했다. API나 고객 데이터 업로드는 사용하지 않았다. [공식 버전별 안내](https://github.com/PriorLabs/TabPFN#license), [v2 라이선스](https://huggingface.co/Prior-Labs/TabPFN-v2-reg/blob/main/LICENSE.txt).

CPU에서 두 추정기·학습 사례 1,000개를 사용했다. 사례는 정답과 무관하게 이벤트 ID 해시 순으로 선택하며, XGBoost도 정확히 같은 사례를 사용한다. TabPFN이 동일 표본 XGBoost보다 소폭 좋았지만 약 0.24일 차이의 안정성은 확인하지 않았다. 이 결과가 최신 버전이나 전체 학습 데이터에서의 우위를 입증하지는 않는다. TabPFN 비교 실행은 약 94초였으며 설치·문제 수정 시간은 포함하지 않는다.

패키지는 프로젝트 `.venv`에 설치했다. XGBoost와 PyTorch를 같은 프로세스에서 사용할 때 네이티브 초기화가 종료 코드 139로 실패해, TabPFN은 독립 로컬 작업 프로세스에서 실행한다. 실패 실행 4개를 `artifacts/tabpfn-experiment-v1-attempt*/`에 보존했다. 첫 1,024개 설정은 CPU 기본 한도로 인해 결과 계산 전에 1,000개로 수정했다.

## 검증과 재현

자동 테스트 **57개**를 통과했다. 저장된 모든 후보의 예측 870,528행에서 키·실제 정답·수량 허용 오차·고객별 날짜 오차를 별도 재계산했다. 생존분석 주간 기회 1,553,776행의 정답과 확률도 확인했다. 후보들이 같은 18,136개 출발 구매를 평가하므로 이 큰 행 수는 서로 다른 고객/구매 수가 아니다.

AFT 저장 모델을 다시 불러와 SciPy 확률 함수로 모든 확률을 대조했다. TabPFN은 각 구간의 8개 예측을 다시 계산해 저장값과 일치함을 확인했고, 첫 예측 뒤의 다른 조회 피처를 바꿔도 첫 결과가 변하지 않았다. 배치 크기에 따른 차이는 최대 약 0.0000153일로 허용한 부동소수점 오차 안이었다. 이 소규모 조회 불변성 점검은 모든 가능한 입력의 증명은 아니다.

```bash
python3 -m scripts.run_timing_experiment
python3 -m scripts.run_survival_experiment
.venv/bin/python -m scripts.run_tabpfn_experiment
python3 -m scripts.verify_timing_experiments
.venv/bin/python -m scripts.verify_tabpfn_context
python3 -m scripts.build_timing_dashboard
```

학습 명령의 기존 출력 경로는 덮어쓰지 않는다. 재학습은 `--output`으로 새 버전을 지정한다. 기본 검증·대시보드 명령은 이번 기본 경로의 결과를 읽는다. TabPFN은 `requirements-tabpfn.txt` 환경과 설정에 명시된 공식 모델 파일이 먼저 필요하다.

근거: [주기 32구성](timing-experiment-v2.json), [확률 14후보](survival-experiment-v1.json), [TabPFN 비교](tabpfn-experiment-v1.json), [전체 대사·관찰 제외 수](timing-verification-v1.json), [TabPFN 재실행·조회 불변성](tabpfn-context-verification.json). 프로토콜: [주기](../timing-experiment-v2.md), [생존분석](../survival-experiment-v1.md).

현재 결과는 최신 상태로 정제한 과거 개발 비교다. 과거 각 예측 시점의 주문 상태 가용성은 검증되지 않았고, 기존 최종 시험을 본 뒤 설계를 바꿨다. 새로운 미래 로그에서 검증하기 전까지 운영 성능이나 자동 적용 승인을 주장하지 않는다. 다음 모델 개선은 과거 시점의 상품 최근 추세·주문 후 경과일을 활용하는 일별 구매 확률을 검토하고, 그 후에 상품 전체 추세 모델의 추가 가치를 비교한다.
