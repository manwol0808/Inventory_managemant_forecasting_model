# 전체 이력 비교와 최종 시험

2026-09-16. [사전 조건·후속 후보·시험 동결](../full-history-experiment.md)에 따라 실행했다. [검증 비교 JSON](history-comparison-v1.json), [최종 시험 JSON](final-test-v1.json), [별도 대사](history-verification-v1.json)가 수치 근거다.

## 결론

전체 이력을 그대로 늘리거나 최근 주문 가중치를 주는 방법은 이번 검증에서 최근 이력 후보를 개선하지 못했다. `xgboost-short-v2`를 시험 후보로 고정했고, 이후 시간 구간에서도 큰 수량 오류와 평균 날짜 오차는 기준 모델보다 작았다. 정확한 정수 개수를 맞히는 비율은 낮아졌고 일부 집단은 악화했다. 운영 승인 모델은 아직 없다.

## 수집과 정제

BigQuery 작업 `forecast_full_20260916_v1`의 단일 결과 테이블 138,427행과 로컬 CSV 138,427행이 일치한다. 2024-10-02~2026-09-15, 주문 54,980개, 고객 11,288명이다. [수집 대사](full-history-ingestion-v1.json). 이전 조회의 138,531행은 9월 16일까지 포함한 다른 범위였으며 누락 비교 기준이 아니다.

상품번호 없는 965행을 이름·SKU로 추정하지 않았다. 해당 339명 고객의 마지막 식별 불가 날짜까지 정상 식별 가능한 183행도 함께 보관해, 미확인 구매를 건너뛴 재구매 연결을 방지했다. 최신 누락일은 2025-03-11이며 총 1,148행을 격리했다. 남은 137,279행의 시작일은 2024-10-16이다. 원본은 변경하지 않았고 전체 원본 셀을 정규화 결과/격리 파일과 대조했다. bq CSV의 시간대 없는 UTC 초 단위 표기에 UTC를 명시했다. 원본 추출·작업 메타데이터를 보존했다.

[상품 규칙](../../config/product-exclusions-full-v1.json)은 83개 코드다. 기존 23개에 명시적 샘플·사은품·충전 복제·테스트 전용 코드를 추가했고, 일반 상품에 사은품이 붙는 프로모션은 유지했다. 개인결제창 2개 코드는 실제 상품 연결 전까지 보류한다. 테스트/정상 이름이 섞인 565번은 일괄 테스트 제외하지 않았고 기존 취소·반품 정책으로 처리했다. 이름이 정확히 테스트인 현재 회원은 2개였고, 격리 뒤 남은 입력에서는 1개 계정의 14행이 제외됐다.

정책 판정은 정상 포함 94,301행, 샘플 32,803행, 충전 2,395행, 사은품 531행, 테스트 상품 69행, 테스트 계정 14행, 취소 5,546행, 나머지 보류다. 일별 정상 구매 90,773개, 관측 재구매 정답 50,217쌍을 생성했다. 최종 학습에 사용한 것은 마감일 안에 정답까지 관측된 43,435쌍이다.

기존 짧은 원본과 겹치는 42,511행의 상세 ID는 일치했지만 703행의 처리 상태가 바뀌었다. 같은 새 스냅샷과 정책으로 짧은 이력 대조군을 다시 만들었다. 기존 학습/검증 키와 정답은 그대로였고, 추가 보류 정책으로 `customer_product_count`가 학습 4행·검증 1행에서 달라졌다. 최종 시험 표본은 상태 갱신으로 기존 747쌍에서 786쌍이 됐다. 시험 점수 확인 후 표본을 바꾸지 않았다.

## 같은 검증 1,196건에서 비교

학습 마감 7월 13일, 내부 조기 종료 경계 6월 23일, 검증 출발일 7월 14일~8월 14일이다. 학습 정답은 해당 학습 경계 이내, 검증 정답은 8월 14일 이내에 있어야 한다. 내부 검증으로 선택한 반복 수를 고정해 전체 학습 풀에 적합한 뒤 외부 검증을 평가했다. 모든 피처는 출발 구매일 전체 이력까지 사용하고 다음 한국 자정에 예측하는 계약이다. 최신 상태를 과거에도 알 수 있었다는 보장은 없다.

| 후보 | 학습 쌍 | 수량 RMSE | 연속 수량 MAE | 정수 수량 MAE | 정확 일치율 | 날짜 MAE |
|---|---:|---:|---:|---:|---:|---:|
| 최근 이력 | 6,579 | 1.6017 | 0.6934 | 0.6179 | 58.44% | 5.5594일 |
| 전체 이력 | 43,435 | 1.7244 | 0.7225 | 0.6405 | 57.86% | 7.6488일 |
| 전체 + 180일 가중치 | 43,435 | 1.8185 | 0.7086 | 0.6288 | 59.28% | 7.2333일 |

최근 후보의 수량/간격은 90/124회, 전체는 171/393회, 가중치는 498/545회를 선택했다. 실행 로그 기준 각각 약 0.56/4.89/6.77초다. 준비·정제·검증 작업 시간은 이 시간에 포함하지 않는다.

실제 다음 수량 6개 이상인 27건에서는 전체/가중치 후보가 오히려 수량 RMSE를 줄였다. 그러나 1개·3~5개 구간 등 다른 사례에서 악화해 전체 주지표는 나빠졌다. 이 구간은 **사후 오류 분석**이며 예측 시점에 실제 다음 수량을 알고 모델을 고르는 규칙으로 쓸 수 없다. 유행 급증 전용 모델이나 최근 상품 추세 피처는 아직 구현하지 않았다.

## 후보 고정 후 최종 시험 786건

시험 출발일 2026-08-15~09-15, 실제 다음 구매는 9월 15일까지다. 최근 이력 후보와 기준 모델 모두 7월 13일까지 적합한 저장 파일을 그대로 사용했다. 시험 전에 후보와 파일 해시를 저장했고 추가 적합·후보 탐색은 하지 않았다.

| 지표 | 직전 수량 기준 모델 | XGBoost 연속 | XGBoost 장바구니 정수 |
|---|---:|---:|---:|
| 수량 RMSE | 1.1046 | 0.9145 | 0.9518 |
| 수량 MAE | 0.5280 | 0.6050 | 0.5242 |
| 정수 정확 일치율 | 67.05% | 해당 없음 | 59.54% |
| 날짜 MAE | 7.7977일 | 4.9809일 | 4.9809일 |
| 날짜 ±7일 비율 | 70.23% | 76.34% | 76.34% |

1·2회 이력 집단의 정수 수량 MAE는 기준 모델보다 나빴다. 6회 이상 집단의 날짜 MAE도 4.0492일→4.4966일로 악화했다. 정수 수량 MAE의 전체 개선은 0.0038개에 불과해 수량 추천이 전반적으로 우수하다고 해석하지 않는다.

시험의 전체 출발 구매 4,956건 중 관측 정답 786건(15.86%)만 평가했다. 나머지는 미관측 3,917건·보류 장벽 253건이다. 관측 종료로 짧은 주기에 치우치며, 검증 점수보다 시험 점수가 낮다는 사실 자체가 모델 개선을 뜻하지 않는다. 실제 재고 소진, 아직 재구매하지 않은 고객, 현재 상태의 과거 가용성을 검증한 결과가 아니다.

이 시험 구간은 사용 완료했다. 결과를 바탕으로 모델·후처리를 바꾸면 새 미래 구간에서 평가해야 한다. 날짜 허용 범위·통과 비율·집단별 적용 조건은 아직 미정이다.

## 확인과 다음 작업

자동 테스트 46개 통과. 검증 예측 3,588건과 최종 시험 786건을 저장 모델로 재계산했고 정답·후처리·지표를 별도 대사했다. 신규 입력 격리와 시간 경계, 최종 시험 전 후보 동결, 모델 입력 정답 차단, 미리보기의 미래 입력/보류 차단과 중복 키 안정성을 확인했다.
