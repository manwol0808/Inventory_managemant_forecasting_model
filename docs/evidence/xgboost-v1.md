# XGBoost 첫 학습 결과

2026-09-16, [사전 고정 실험](../xgboost-contract.md)으로 수량과 다음 구매 간격을 각각 학습했다. 저장 경로 `artifacts/xgboost-v1/`, 집계·해시 사본은 [JSON](xgboost-v1.json)이다. XGBoost 3.2.0, NumPy 2.4.3, Python 3.14.6에서 실행했다.

설정·21개 피처·후처리·수량 RMSE 주지표는 이 XGBoost 검증 결과를 보기 전에 고정했다. 이미 관찰한 기준 모델과 비교하는 개발 검증이며 잠금 시험 결과나 운영 검증은 아니다. 검증 결과를 본 뒤 추가 튜닝·재학습하지 않았다.

## 같은 검증 1,196쌍의 비교

| 지표 | 기준 모델 | XGBoost 연속 수량 | XGBoost 장바구니 정수 수량 |
|---|---:|---:|---:|
| 수량 RMSE · 주지표 | 1.7665개 | 1.5979개 | 1.6226개 |
| 수량 MAE | 0.6288개 | 0.6937개 | 0.6212개 |
| 날짜 MAE | 8.4423일 | 5.5602일 | 5.5602일 |
| 정수 수량 정확 일치율 | 63.13% | 해당 없음 | 58.03% |

연속 수량 RMSE는 9.54% 감소했으나 수량 MAE는 10.33% 증가했다. 장바구니용 정수로 바꾸면 RMSE는 8.14%, MAE는 1.20% 감소하지만 정확히 같은 개수를 맞힌 비율은 떨어진다. 연속값과 정수값 중 유리한 값만 선택해 주지표로 보고하지 않는다.

날짜 MAE는 34.14% 감소했다. 반올림 후 실제 예측일 기준이며 평균 편향 `예측일−실제일`은 +5.95일에서 −3.89일로 바뀌었다. 전체적으로 빨리 예측하는 경향이 생겼으므로 절대 오차 개선만으로 업무 적합성을 확정하지 않는다.

2회 집단의 수량 RMSE와 6회 이상 집단의 날짜 MAE는 악화됐다. 상품 사전 밖 검증 29쌍에서는 수량 MAE가 0.7241→0.9126개로 증가했다. 전체 수량 RMSE 개선으로 집단별 악화를 상쇄해 통과로 처리하지 않는다.

## 학습과 확인 범위

실행 로그의 `run_finished`는 `completed`이며 전체 실행 소요 시간은 0.9646초다. 이는 데이터 정제·코드 구현·사후 검증·대시보드 작업 시간을 포함하지 않는다. Grafana는 완료된 실행의 저장 곡선을 표시한다. XY 패널에 `pluginVersion: 12.1.1`을 명시해 구버전 수동 매핑으로 변환되던 오류를 수정했으며, 브라우저에서 수량·간격 두 곡선의 정상 표시를 확인했다.

내부 조기 종료에서 수량 90회, 간격 124회를 선택했다. 실제 탐색은 개선 없이 50회가 지난 각각 140회·174회까지 진행됐다. 90/124회로 잘라낸 내부 최적 모델과 그 반복 수로 train_pool에 새로 학습한 최종 모델을 따로 저장했다. core 4,654 + early_stop 399 외에 내부 경계를 넘지만 전체 학습 마감 전에 알려진 정답 1,526쌍을 포함해 최종 학습은 6,579쌍이다.

학습 곡선의 `train_core`와 `early_stop`은 역할과 기간이 다른 모집단이다. 간격 모델은 core에서 관측 가능한 긴 간격과 짧은 early_stop 구간의 분포가 달라 내부 검증 오차가 학습 오차보다 작을 수 있다. 곡선만으로 전체 고객에 대한 과적합 없음이나 운영 성능을 판정하지 않는다.

- 자동 테스트 39개 통과. 범주 사전·순서·신규/결측·정답 입력 차단·조기 종료 반복 수·재학습·저장/재로딩·기준 정답 불일치 거부·모니터링 실패/완료 구분을 확인했다.
- 실제 검증 1,196건의 키·정답을 기준 모델과 대조했다. 독립 계산으로 연속 수량·정수 수량·날짜·핵심 지표를 확인했고 저장 모델 재로딩 후 전체 검증 원시 예측이 일치했다.
- 최종 시험 파일은 실행 입력 목록에 없고 시험 점수를 계산하지 않았다. 현재 상품 추세·스파이크 보정과 2024년 이력 확장은 미구현이다.

## 해석과 다음 실험

현재는 최신 상태 스냅샷을 사후 정제한 탐색 결과다. 검증 출발 구매 5,633개 중 마감 전에 재구매가 확인된 21.23%만 평가했고 당시 상태 가용성은 미검증이다. 운영 가드레일은 판단 보류이고 이번 모델을 자동 채택하거나 장바구니에 배포하지 않았다.

다음 전체 이력 실험은 확보 가능한 2024-10-02 이후 자료를 같은 상태·제외 정책으로 정제하되 각 학습/예측 시점 이후의 정보는 사용하지 않는다. 현재 버전과 같은 검증 기간 및 공통 평가 대상으로 비교한다. 더 긴 이력 확보만으로 과거 상태 가용성이 해결되지는 않는다. 운영 검증에는 당시 상태 이력이나 앞으로 쌓을 실제 예측 로그가 필요하다.
