# 첫 기준 모델 결과

2026-09-16 실행. [사전 고정 규칙](../baseline-contract.md)으로 학습 간격 6,579쌍을 적합하고 검증 1,196쌍을 평가했다. 상세 산출물은 `artifacts/baseline-v1/`, 집계·해시 사본은 [JSON](baseline-v1.json)이다.

| 검증 지표 | 결과 |
|---|---:|
| 수량 RMSE · 주지표 | 1.7665개 |
| 수량 MAE | 0.6288개 |

| 수량 WAPE | 33.16% |
| 평균 수량 편향 · 예측−실제 | −0.1104개 |

| 평균 날짜 편향 · 예측−실제 | +5.9507일 |
| 날짜 ±7일 이내 · 설명용 | 63.55% |

수량은 모든 사례에서 직전 구매일 개수를 반복한다. 날짜는 개인 간격 1,020건, 상품 대체 127건, 전체 대체 49건이다. 전체 학습 간격 중앙값은 17일이다. 날짜 예측은 평균적으로 실제보다 늦었지만 짧은 간격만 검증 마감 전에 관측되는 선택 편향의 영향도 있어 원인을 단정하지 않는다.

| 보류 이후 관측 구매 횟수 | 검증 쌍 | 수량 MAE | 날짜 MAE |
|---|---:|---:|---:|
| 1회 | 176 | 0.5511개 | 7.9261일 |
| 2회 | 117 | 0.6496개 | 22.3590일 |
| 3~5회 | 405 | 0.6346개 | 10.1160일 |
| 6회 이상 | 498 | 0.6466개 | 3.9940일 |

2회 집단은 개인 간격 하나만으로 예측하는 집단이다. 오차가 크지만 이 표만으로 대체 규칙의 우열이나 인과관계를 확정하지 않는다. 기준 모델 규칙은 결과를 본 뒤 변경하지 않았다.

횟수는 사람 전체의 구매 횟수가 아니라 **예측 시점의 고객·상품별 이력 횟수**다. 동일 고객의 원두 3회와 시럽 3회는 6회로 합치지 않는다. 한 쌍이 여러 예측 시점에 평가되거나 다른 횟수 집단으로 이동할 수 있다. 6회 이상 집단의 3.9940은 수량이 아닌 날짜 MAE(일)이며, 498건의 절대 날짜 오차 합계 1,989일을 498로 나눈 값이다. 모든 예측이 ±4일에 들어간다는 뜻은 아니다.

## 해석 범위

검증 출발 구매 5,633개 중 마감 전 재구매 정답이 확인된 21.23%만 평가했다. 미관측·경계 초과·보류 사례는 정확도 분모에 없다. 최신 주문 상태의 과거 가용성도 미검증이므로 **탐색용 비교 기준**이며 전체 고객·운영 성능이 아니다. 시기·집단 업무 한도가 없어 가드레일은 판단 보류다. 최종 시험 파일은 실행 코드가 읽지 않았고 시험 점수는 계산하지 않았다.

## 확인한 내용

- 자동 테스트 33개 통과. 새 기준 모델 테스트 6개는 개인/상품/전체 대체, 날짜 반올림, 저장·재로딩, 미래 정답 적합 거부, 정답 변경의 예측 독립성, 손계산 지표, 실행 실패·이전 지표 초기화와 전체 실행을 검사한다.
- 최종 시험 파일이 없는 합성 입력으로 전체 실행이 성공했다. 검증 정답 수량을 바꿔도 모델과 예측이 그대로였다.
- 실제 검증 예측 1,196행을 원본 검증값에 연결하고 직전 수량·각 간격·예측일을 별도 코드로 재계산했다. RMSE·MAE·수량 일치율·날짜 MAE·±7일 비율이 보고서와 일치했다. 집단·대체 규칙의 표본 합계도 일치했다.
- Grafana API의 정상 상태와 브라우저에서 수집 연결·완료·판단 보류·전체/집단 점수 표시를 확인했다. 표시된 반올림 수치가 파일과 일치했다.
- 신선한 문서 검토에서 지적된 정상 상태 계약 연결, 날짜 마감 시각, 학습 간격 0개 실패 처리를 명시했다. 누수 점검에서는 정답 출처가 실제 다음 구매인지, 검증 정답이 적합에 들어가지 않는지 확인했다. 최신 상태 선택 및 마감 전 재구매만 평가하는 한계는 해결했다고 주장하지 않는다.

XGBoost 학습, 다중 시간 fold, 업무 승인, 운영 자동 장바구니 반영은 이번 실행 범위가 아니다.
