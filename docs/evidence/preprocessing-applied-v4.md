# 첫 모델용 전처리 범위 적용 완료

2026-09-16. 사용자의 계속 진행 지시에 따라 샘플 15개 상품코드와 명시적 사은품 2개 상품코드를 자동 보충 대상에서 제외했다. 이전에 확인한 충전 상품 6개 코드와 테스트 계정 1개 제외도 유지한다. [상품코드별 설정](../../config/product-exclusions-v2.json), [실행 집계](preprocessing-applied-v4.json).

처리는 고정된 상품코드 목록으로 적용한다. 상품명에 사은품이라는 글자가 있다는 이유로 일반 행사 상품을 제외하지 않는다. 샘플·사은품과 함께 주문한 정상 상품과 고객의 다른 구매 이력은 유지한다. 원본 파일은 삭제하거나 덮어쓰지 않았다.

## 현재 행 판정

| 처리 | 원본 상세 행 수 |
|---|---:|
| 정상 구매 포함 | 30,328 |
| 샘플 제외 | 9,217 |
| 명시적 사은품 제외 | 329 |
| 충전 상품 제외 | 594 |

| 합계 | 42,511 |

각 행은 표의 한 항목에만 속한다. 우선순위는 테스트 계정 → 제외 상품코드 → 주문·상품 상태다. 따라서 취소된 샘플은 샘플 제외에 집계된다. 취소 행이 정상 구매로 바뀐 것은 아니다. 원본 상태와 상세 식별자는 그대로 남는다.

## 구매일과 정답

- 정상 구매일: **29,473개**
- 다음 구매 날짜·수량 정답: **12,920쌍**, 고객·상품 4,765개 조합
- 보류 때문에 연결이 끊긴 출발 구매: 503개
- 다음 구매가 아직 관측되지 않은 출발 구매: 16,050개

정상 구매일 하나마다 세 정답 상태 중 하나가 붙는다. 충전 상품·테스트 제외 후 13,206쌍에서 샘플 113쌍과 사은품 173쌍이 추가로 빠졌다. 12,920쌍은 시간 분할 전 전체 관측 정답이며 최종 학습 표본 수가 아니다.

`data/purchase-policy-v4/rows.csv`는 전체 원본에 사유를 붙인 판정 파일이다. `data/purchase-events-v4/`에는 일별 기록, 원본 연결표, 모든 정상 출발 구매의 정답 상태, 관측 정답 쌍이 있다. 제외된 날짜는 `excluded_only` 추적 기록으로 남는다. 이 날짜를 모델 입력·구매 횟수·간격·정답 계산에 사용하지 않는다. 보고서 전체 고객·상품 조합 수는 추적 대상 수이며 모델 대상 수가 아니다.

## 검증과 다음 단계

원본 42,511행의 모든 열과 연결을 대조했다. 제외하지 않은 상품·고객의 날짜 기록과 정답은 최초 버전과 완전히 일치한다. 제외 대상은 정답 쌍에 남아 있지 않다. 원본 수량과 모든 판정별 수량을 대사했고 정상 포함 수량 46,411개는 날짜별 합산 기여와 일치했다. 이 합계는 다양한 포장 상품의 주문 개수 대사이며 중량/소비량 통계가 아니다. 임시 새 경로로 재실행한 CSV 해시도 같았다. 자동 테스트 20개가 통과했다.

이로써 4단계의 첫 실험용 상태·상품·테스트 제외와 구매 연결을 완료했다. 대량 주문·0원 결제·단순 이름 변경은 오류라는 근거 없이 삭제하지 않는다. 옵션 및 묶음 상품 수량은 상품코드의 주문 개수로 유지한다. 구성 변경이 확인될 때의 재처리는 별도 개선 항목이다.

다음은 **5단계: 과거 입력값·예측 기준 시각·시간순 분할**이다. 아직 피처 생성과 모델 학습은 하지 않았다. 최신 스냅샷의 과거 상태 가용성과 마지막 날짜 완전성이 미확인이라 `training_ready=false`이며, 이를 해결하기 전 성능은 사후 정제 탐색 결과로만 다룬다.

```bash
python3 -m scripts.apply_training_policy data/order-items-v2.csv --output-dir data/purchase-policy-v4 --product-exclusions config/product-exclusions-v2.json --customer-exclusions data/test-account-exclusions-v1.json
python3 -m scripts.build_purchase_events data/purchase-policy-v4/rows.csv --policy-report data/purchase-policy-v4/report.json --output-dir data/purchase-events-v4
```

출력이 존재하면 새 폴더를 사용한다. v2~v4는 전처리 버전이며 학습 기간을 늘리는 모델 버전과 다르다.
