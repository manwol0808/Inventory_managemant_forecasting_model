# 같은 전처리의 전체·짧은 이력 재학습 비교

2026-09-17. 사용자 요청 해석: 2024년부터의 전체 이력에 적용했던 고객 유형·품목 속도·신제품 처리·늦음 가중 학습을 2026년 4월부터의 기존 정제 자료에도 그대로 적용하고, 같은 평가 사례에서 차이를 분석한다.

**현재 챔피언을 교체할 만큼 명확한 개선은 확인하지 못했다.** 이번 공통 검증에서 짧은 이력 후보는 늦은 제안이 적었지만 지나치게 이른 제안이 많았다. 평가한 10일 범위 적중률의 최고 후보는 챔피언보다 3건 더 맞췄을 뿐이다. [전체 수치와 출처](segment-history-comparison-v1.json), [저장 예측 재검증](purchase-segments-short-verification-v1.json).

## 같은 것과 다른 것

`data/purchase-events-short-v2`와 `data/features-splits-short-v2`를 사용했다. 어제의 테스트 계정·충전·샘플·사은품·테스트 상품 제외 및 보류 장벽은 전체 이력과 같은 정책이다. 추가 전처리 함수·최근 6개 간격·그룹 문턱·품목 최근 100간격·활성화 20간격/5고객·전문 모델 200건/30고객·학습률·반복 수·8개 후보를 그대로 유지했다. 그 이전 이력은 고객 분류와 품목 통계에도 넣지 않았다.

| 항목 | 전체 이력 | 짧은 이력 |
|---|---|---|
| 데이터 시작 | 2024-10-16 | 2026-04-09 |
| 데이터 종료 | 2026-09-15 | 2026-09-15 |
| 공통 비교의 학습 정답 마감 | 2026-07-13 | 2026-07-13 |
| 학습 쌍 | 43,435 | 6,579 |
| 학습 정답 간격 중앙값 | 22일 | 17일 |
| 학습 정답 간격 90분위 | 73일 | 45일 |
| 실제 전문 모델을 학습한 유형 | 이력 부족 외 5유형 | 불규칙형만 |

짧은 이력 출발점 29,563건을 보존했다. 학습 시 유형은 이력 부족 4,762건, 불규칙 1,447건, 일정 159건, 점점 짧아짐 69건, 반등 29건, 계속 길어짐 113건이다. 불규칙형 외에는 전문 모델 최소 표본을 충족하지 못해 전체 모델로 되돌아간다. 따라서 짧은 이력의 ‘전문 모델’은 모든 고객군에 독립 모델이 있는 구성이 아니다.

검증은 두 이력 모두 동일한 1,196개 출발점·정답, 444명 고객이다. 고객 유형은 이력 길이에 따라 달라지므로 유형별 비율끼리 직접 효과를 비교하지 않았다. 공통 검증에서 품목 속도를 사용할 만큼 표본이 쌓인 사례는 전체 1,056건, 짧은 이력 983건이다.

4~6월의 기존 90일 평가 구간은 짧은 이력에서 필요한 학습 과거가 없으므로 억지로 실행하지 않았다. 4월 구간은 3월 31일까지 학습해야 하고, 6월 구간도 5월 말보다 90일 앞선 출발점이 필요하다. 이번 검증은 7월 14일~8월 14일 출발점 중 8월 14일 안에 재구매까지 확인된 1,196건이며 모든 출발점의 90일 미래를 관찰한 자료가 아니다. 이미 여러 후보를 비교한 개발 자료이므로 별도 새 시험이나 미래 운영 성능으로 해석하지 않는다.

## 결과

모두 **예측 간격의 25%, 최대 7일 전**에 제안하며 구매 다음 날보다 빠르지 않다. 범위 적중은 **실제 재구매일 10일 전~당일 포함**이다. ‘10일보다 이른 제안’은 예측일 기준이 아닌 실제 재구매일 기준이다. 당일은 별도 집계에도 남겨 두었다.

| 후보 | 10일 범위 적중 | 늦은 제안 | 10일보다 이른 제안 | 날짜 ±7일 | 수량 ±2개 |
|---|---:|---:|---:|---:|---:|
| 기존 챔피언 | 65.64% | 11.71% | 22.66% | 72.99% | 97.32% |
| 전체 이력·통합 피처·늦음 3배 | 64.97% | 20.57% | 14.46% | 76.92% | 97.07% |
| 짧은 이력·통합 피처·늦음 3배 | 63.46% | 5.60% | 30.94% | 63.04% | 96.91% |
| 짧은 이력·전문 모델·대칭 비용 | 65.89% | 9.78% | 24.33% | 70.07% | 96.91% |
| 짧은 이력·전문 모델·늦음 3배 | 65.05% | 5.52% | 29.43% | 64.97% | 96.91% |

8개 짧은 이력 후보의 범위 적중은 63.46~65.89%였다. 전문 모델·대칭 비용의 65.89%는 788/1,196건으로 챔피언의 785건보다 3건 많다. 늦음은 140→117건, 지나친 조기는 271→291건이다. 세 항목은 같은 분모를 완전히 나누며 범위 적중에는 당일도 포함한다.

전체·짧은 이력의 같은 후보끼리 비교하면 이력 길이 효과를 볼 수 있다. 챔피언 대비 비교에는 학습 목적함수·모델 구성 차이도 포함되므로 그 차이를 전부 이력 길이 때문으로 돌리지 않는다.

고객 단위로 묶어 2,000회 재표집한 짝지은 부트스트랩에서 이 후보의 챔피언 대비 범위 적중 차이 +0.25%p의 95% 구간은 약 **−1.64~+2.13%p**였다. 명확한 우세 근거가 없다. 이는 여러 후보를 본 개발 자료의 탐색적 구간이며 다중 비교 보정이나 새 독립 시험은 아니다.

늦음 3배 전문 모델은 늦음을 140→66건으로 줄였지만 10일보다 이른 제안은 271→352건으로 늘었다. 사용자가 이른 제안도 부담으로 본다는 점에서 지연 감소만으로 우승을 선언하지 않는다.

## 해석과 다음 방향

1. **짧은 이력은 예측을 더 이르게 만드는 쪽으로 움직였다.** 같은 피처와 3배 비용에서 지연은 20.57%→5.60%지만 과도한 조기는 14.46%→30.94%다. 최근 환경 변화 때문인지, 짧은 관찰 기간에 빠른 재구매 정답이 많이 남는 구조 때문인지는 이 비교로 분리하지 못했다. 학습 간격 분포가 다르므로 ‘최근 데이터라 더 정확하다’고 단정하지 않는다.
2. **유형별 모델을 나누기에는 짧은 학습 표본이 부족하다.** 이력 부족과 작은 유형을 삭제하지 않고 전체 모델을 사용하는 것이 현재 구현이다. 고객 패턴 피처와 품목 피처는 사용하되 모두 독립 모델로 쪼개는 효과는 확인하지 못했다.
3. **예측 날짜와 장바구니 일정은 구분해야 한다.** 위 분석 뒤 사용자는 ‘목요일 예상이면 전주 월요일 또는 일요일 밤에 담기’가 원하는 동작이라고 명확히 했다. 따라서 운영 동작은 [예측일 10일 전 제안](../app-integration-contract.md)을 기준으로 하고 실제 구매일의 10일 범위 비율은 설명용 진단으로 남긴다. 이를 무조건 최대화하는 새 모델로 변경하지 않았다.

이 검증은 기간 마감 안에 재구매한 대상만 포함하므로 긴 주기·미재구매에 관한 효과를 말하지 못한다. 30일 초과 조기 제안이 여기서 0이라는 것도 전체 문제 해결의 증거가 아니다. 전체 이력의 90일 관찰에서 드러난 불필요한 제안과 조기 제안 문제는 별도 미래 검증이 필요하다.

## 재현

학습: `.venv/bin/python -m scripts.run_purchase_segments --config config/purchase-segments-short-v1.json --output artifacts/purchase-segments-short-v1`

검증: `.venv/bin/python -m scripts.verify_purchase_segments artifacts/purchase-segments-short-v1`

비교: `.venv/bin/python -m scripts.compare_segment_history`

기존 모델과 출력은 덮어쓰지 않았다. 챔피언·미리보기 기본 10일·실제 앱은 이번 짧은 이력 학습으로 변경하지 않았다.

관련 테스트 11개가 통과했다. 짧은 이력 29,563개 출발점과 직전 품목 간격을 별도 날짜 차이 계산으로 대조했고, 저장 모델 예측 9,568건과 36개 정책 집계를 재검증했다.
