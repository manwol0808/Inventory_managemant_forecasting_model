# 규칙적인 품목 이력만 학습한 비교

2026-09-16. 사용자가 제안한 대로 과거 구매 횟수뿐 아니라 간격의 규칙성으로 학습 사례를 골라 수량·주기 XGBoost를 새로 학습했다. 같은 규칙적 평가 대상에서 ±7일 적중률은 55.2%에서 55.9%로 조금 개선됐고, 수량 ±2개는 98.3%에서 98.0%로 낮아졌다. 현재 챔피언은 교체하지 않았다.

## 포함 기준

단위는 고객×상품이다. 서로 다른 상품의 구매 간격을 합치지 않는다. 예측 기준일까지 관측된 간격 중 최근 최대 5개의 모집단 표준편차(ddof=0)/평균이 0.5 이하이고 간격이 최소 3개 있어야 포함한다. 따라서 최소 4회 구매가 필요하다. 2회·3회 구매는 별도 이력 구간으로 보고하지만 규칙성 판정은 유보한다.

- `14·21·28·14일`: 포함한다.
- `30·30·30일`: 포함한다.
- `2·60·2·60일`: 이 실험의 규칙적 학습에서는 제외한다. 원본을 삭제하거나 잘못된 주문으로 단정하지 않는다.

다음 구매 간격이나 평가 결과를 이용해 포함 여부를 정하지 않는다. 보류 이벤트 뒤에는 해당 고객×상품의 유효 이력을 다시 쌓는다. 최근 5개가 규칙적이라는 조건은 모든 과거 구매가 일정했다는 뜻이 아니다. 기준은 실행 전에 고정했으며 점수를 본 뒤 문턱을 바꾸지 않았다.

규칙성 선별은 예측 시점 이전의 구매 간격만 사용했다. 다만 상태 스냅샷의 당시 가용성은 미검증이므로 모든 피처가 실제 그때 알려져 있었다는 것까지 검증한 결과는 아니다.

## 공통 비교 조건

[전체 이력 90일 평가](cadence-groups-v1.md)와 같은 피처·학습 설정·평가 대상을 사용했다. 4월, 5월, 6월 1~16일 구매 기준일을 평가하며 모델 학습 마감은 각각 3월 31일, 4월 30일, 5월 31일이다. 모델은 구간별 고정하고 입력은 각 구매일까지의 과거 이력으로 갱신한다. 학습에 들어가는 구매 기준일은 마감일까지 90일 관찰을 완료해야 하고, 정답은 그 안의 다음 구매일 간격과 그 구매일 수량 합계다.

| 평가 구간 | 전체 학습 사례 | 규칙적인 학습 사례 | 규칙적 학습 고객 수 |
|---|---:|---:|---:|
| 4월 | 24,239 | 10,084 | 808 |
| 5월 | 28,106 | 10,983 | 866 |
| 6월 1~16일 | 30,724 | 11,822 | 929 |

각 구간의 수는 겹치는 학습 이력을 포함하므로 더해서 고유 사례 수로 해석하지 않는다. 새로운 모델은 absolute-error 목적함수, 깊이 4, 200회 학습을 수량·주기에 각각 사용했다. 다른 모델 조건을 고정하고 학습 사례 포함 조건만 바꾼 비교다.

## 결과

모든 예측 대상 15,491건 중 과거 간격 기준을 충족한 대상은 3,117건(20.1%)이다. 이 중 90일 내 재구매한 2,732건에서 오차를 계산했다. 384건은 90일 내 재구매가 없고 1건은 보류로 결과 불명이다. 아래 두 모델은 동일한 2,732건에서 평가했다.

비교 기준인 전체 이력 학습 모델은 90일 실험의 `cadence-groups-full-v1/global`이다. 현재 챔피언 `xgboost-short-v2`와는 다른 모델이다.

| 학습 방식 | 주기 ±7일 | 주기 ±14일 | 날짜 MAE | 고객별 동일 가중 MAE | 수량 ±2개 |
|---|---:|---:|---:|---:|---:|
| 전체 이력 학습 | 55.2% | 77.0% | 10.46일 | 13.98일 | 98.3% |
| 규칙적 이력만 새 학습 | 55.9% | 76.2% | 10.39일 | 13.91일 | 98.0% |

±7일 적중은 17건 늘었지만 ±14일과 수량 점수는 낮아졌다. 고객별 동일 가중 MAE는 약 0.07일 낮아졌다. 같은 고객을 짝지어 재추출한 기술적 부트스트랩에서 차이(규칙적 학습−전체 학습)의 95% 범위는 -0.25~+0.10일로 0을 포함했다. 이는 독립 최종 시험이나 모델 선택을 보정한 통계 검정이 아니다. 큰 개선이 검증됐다고 보지 않는다.

| 과거 구매 횟수 | 규칙적 재구매 평가 건 | 전체 학습 ±7일 | 규칙적 학습 ±7일 |
|---|---:|---:|---:|
| 2회 | 0 | 규칙성 판단 유보 | 규칙성 판단 유보 |
| 3회 | 0 | 규칙성 판단 유보 | 규칙성 판단 유보 |
| 4회 | 264 | 38.3% | 42.0% |
| 5회 | 199 | 45.7% | 44.7% |
| 6회 이상 | 2,269 | 58.0% | 58.4% |

2회·3회 사례 자체가 없다는 뜻이 아니다. 이 실험의 규칙성 판정에 필요한 간격 수가 부족하여 위 표의 대상에서 제외했다. 전체 사례의 정확한 1회·2회·3회·4회·5회·6회 이상별 진단은 [기계 판독 집계](regular-history-v1.json)의 `purchase_buckets`에 보존했다. 같은 고객이 여러 구매 기준일과 품목에 등장하므로 평가 건수는 고객 수가 아니다.

규칙적인 평가 대상만 골라 점수가 높아진 효과와 규칙적 사례로만 학습한 효과를 구분한다. 전체 대상 15,491건 중 90일 내 재구매가 관측된 사례가 7,551건이며, 41.1%는 이들에 대한 점수다. 55.2%는 그 모델을 규칙적 부분집합 2,732건에서 평가한 점수다. 학습 변경의 비교는 55.2% 대 55.9%다. 기존 챔피언의 73~76%와는 평가 계약이 달라 직접 비교하지 않는다.

## 검증과 산출물

과거 기준의 학습 ID 선별, 미래 구매 추가 시 과거 분류 불변성, 보류 후 초기화, 사용자의 두 예시를 점검했다. 저장 모델 재로드로 30,982개 예측을 대조하고 pandas로 집계 지표를 별도 계산했다. [검증 기록](regular-history-verification.json). 전체 테스트 63개가 통과했다.

최신 상태 스냅샷의 과거 가용성은 미검증이고 기존 개발 구간을 재사용했다. 미구매 대상에도 날짜를 내놓는 문제를 해결한 실험은 아니다. 출력은 `artifacts/regular-history-v1/`이며 원본·기존 모델은 보존했다. 재실행은 산출물 경로가 없는 별도 작업 복사본에서 `.venv/bin/python -m scripts.run_regular_history`로 수행한다.

[챔피언과 전체 벤치마크 화면](http://127.0.0.1:3008/d/forecasting-benchmarks)의 **05-R** 구역에 같은 비교를 표시한다.
