# 주기 우선 비교 v2

실행·검증을 완료했다. [종합 결과](evidence/timing-model-comparison-v1.md), [32구성 전체 점수](evidence/timing-experiment-v2.json), [Grafana](http://127.0.0.1:3008/d/forecasting-timing-models)를 참고한다.

2026-09-16 요청 해석: 주기를 더 중요하게 보고 수량은 ±1~2개 범위를 허용하는 방향으로 조건을 바꾼 후보들을 학습·비교한다. 고객·상품별 이력을 유지하고 고객별 성능도 확인한다. 주기 완전 일치를 보장하거나, 이미 확인한 시험 점수를 새 독립 시험으로 재사용하지 않는다.

설정은 [timing-experiment-v2.json](../config/timing-experiment-v2.json)에 **결과 확인 전에 고정**한다. v1은 수량 RMSE 우선 실험이고 v2는 고객별 날짜 MAE 우선 실험이다. 둘의 승자를 같은 기준의 승자로 설명하지 않는다.

## 평가 모집단

전체 정제 이력 `data/purchase-events-full-v1/`와 시점별 21개 피처를 사용한다. 평가 출발 구매월은 2026년 4·5·6월이며, 각 월 전일까지 학습한다. 각 출발 구매 뒤 **60일을 동일하게 관찰**한다. 마지막 관찰일은 8월 29일로 수집 끝인 9월 15일보다 앞선다.

60일 안에 정상 재구매가 관측된 경우만 날짜·다음 수량 오차를 계산한다. 60일 안에 재구매가 없는 경우는 0개 정답으로 만들지 않고 별도 집계한다. 그 경우에도 모델이 60일 이내 날짜를 제시한 비율을 보고해, 재구매자만의 좋은 날짜 점수를 모든 고객 성능으로 오해하지 않게 한다. 60일 안에 보류 장벽이 있으면 관측 불명으로 분리한다. 60일은 관찰 기간이며 재고 소진 주기나 허용 오차가 아니다.

학습은 출발 구매일이 학습 마감에서 180일 또는 90일 이내이되, **60일 관찰이 이미 끝난 출발 구매만** 사용한다. 정답도 그 구매 이후 60일 안에 있어야 한다. 늦은 학습 출발일의 빠른 재구매만 골라 학습하는 편향을 줄인다. 피처는 각 출발 구매일까지의 식별 가능한 전체 과거 이력으로 고정한다. 90/180일은 학습 예제 선택 창이지 피처 이력 창이 아니다.

## 후보와 비교

각 학습 창마다 개인 주기 중앙값·마지막 간격·최근 3간격 중앙값 규칙, XGBoost 4설정, 개인 최근 주기와 XGBoost를 결합한 후보를 비교한다. 각 날짜 후보에 직전 수량 또는 최근 3수량 중앙값을 붙여 총 32개 구성을 3개 과거 구간에서 비교한다. 고객별 별도 AI를 만드는 대신 전역 AI가 고객·상품별 과거 피처를 읽는다. 규칙 후보는 해당 고객·상품의 개인 이력을 직접 사용한다.

XGBoost는 고정된 깊이·반복 수·손실만 비교한다. 로그 간격 후보만 `log1p` 정답과 `expm1` 복원을 사용한다. 추가 조기 종료 탐색이나 점수 확인 뒤 후보 추가는 하지 않는다. 모델이 부족한 주기 이력에 대응하는 방법도 고정한다: 규칙은 같은 학습 창의 상품 간격 중앙값(최소 5개) → 전체 중앙값 순으로 대체한다. 결합 후보는 과거 간격 3개 이상이면 개인 최근 3간격 중앙값, 그보다 적으면 abs_d2_200을 사용한다.

주지표는 고객마다 날짜 MAE를 계산한 뒤 고객들에게 동일 가중치를 주는 **고객 평균 날짜 MAE**다. 예측 건수 가중 날짜 MAE, ±3일/±7일 비율, 정확 날짜 비율도 표시한다. 수량은 ±1/±2개 비율, 정수 정확 일치율·MAE, 작은 수량 및 과다/과소 오류를 같이 보고한다. ±1개 비율이 같은 창의 개인 중앙값 주기+직전 수량 기준보다 떨어지는 후보는 우선 후보에서 제외한다. ±2개는 더 느슨한 보조 기준이며 작은 주문에서는 큰 상대 오차가 될 수 있다.

고객별 로그는 로컬 파일에만 저장하고 Grafana/문서에는 집계를 표시한다. 기간별·이력별 성능과 표본 수도 함께 보고한다. 선택 결과는 개발 후보이며, 업무상 통과율·운영 승인 기준을 임의로 확정하지 않는다.

## 한계

최신 상태로 과거 이력을 정제한 자료이며 당시 상태 가용성은 미검증이다. 재구매는 실제 재고 소진의 대리 지표다. 60일보다 긴 주기 고객과 관측 불명 고객의 정확한 다음 날짜 성능은 별도로 남는다. 앞선 최종 시험을 본 뒤 새 방향을 잡았으므로 v2 결과를 독립적인 최종 성능이라고 부르지 않는다. 실서비스 개선은 새로운 미래 예측·후속 주문 로그로 확인해야 한다.
