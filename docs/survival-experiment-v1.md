# 재구매 확률 비교 v1

실행·검증을 완료했다. [종합 결과](evidence/timing-model-comparison-v1.md), [전체 점수](evidence/survival-experiment-v1.json), [월·주차별 관찰 제외 수](evidence/timing-verification-v1.json)를 참고한다.

목표는 고객·상품의 출발 구매 이력을 읽고, 아직 재구매하지 않은 시점에서 다음 7일 안에 재구매할 확률을 추정하는 것이다. 실제 재고 소진을 관측한 모델은 아니다. 설정은 학습 전에 [JSON](../config/survival-experiment-v1.json)으로 고정했다.

## 학습과 평가

[주기 비교 v2](timing-experiment-v2.md)와 같은 2026년 4·5·6월 출발 구매 18,136건을 평가한다. 각 월 전일까지 학습하며, 학습 마감 기준 90/180일 창에서 이미 60일의 관찰 기회가 있었던 출발 구매를 사용한다. 피처 21개는 출발 구매일까지의 이력으로 고정된다. 미래 주문은 피처에 넣지 않는다.

60일 안에 다음 정상 구매가 있으면 정확한 간격을 학습한다. 없으면 적어도 60일 동안 재구매가 없었다는 오른쪽 검열로 학습한다. 보류 상태가 생기면 그 날짜 자체는 정상 구매 여부를 모르는 날이므로 전날까지만 관찰한 것으로 처리한다. 보류의 발생이 구매 성향과 무관하다는 보장은 없어 해석에 한계가 있다.

XGBoost AFT의 normal/logistic 분포, 척도, 깊이를 고정한 6설정과 학습 집단의 Kaplan–Meier 기준 모델을 각 창에 적용한다. 총 14후보·3구간, AFT 학습 36회다. 모든 반복 수는 300이며 평가 점수로 조기 종료하지 않는다. 수량은 직전 수량으로 통일한다.

확률 평가는 출발 구매 후 0·7·14·21·28·35·42·49일에 아직 재구매하지 않은 사례를 대상으로 한다. 각 시점부터 7일 내 구매 여부를 정답으로 쓴다. 창 안에서 구매가 관측되면 양성, 구매 없이 창 끝까지 관찰되면 음성, 그 전에 보류가 생겨 결과를 알 수 없으면 제외한다. 평가 정답은 예측값이 아닌 실제 후속 주문으로 구성한다. 이것이 학습·평가 표본의 통계적 독립성을 보장하는 것은 아니다.

AFT와 KM 모두 `P(t<T≤t+7 | T>t) = 1−S(t+7)/S(t)`를 계산한다. 이번 KM 후보의 평가 시점에서 `S(t)>0`인지는 산출물 검증에서 확인한다. 0이면 조건부 확률이 정의되지 않으므로 그 실행 결과를 사용하지 않는다. 보류가 생기면 그 이후 주차는 제외하며 뒤의 정상 구매로 원래 출발 구매의 정답을 복원하지 않는다. 수집 종료일은 2026-09-15로, 마지막 출발 구매 2026-06-30의 60일 관찰 종료인 8월 29일보다 늦다.

학습 창은 출발 구매일 기준 `[마감−(창 크기−1)일, 마감−60일]`이다. 90일 설정의 경우 60일 성숙 기간 이전의 30개 달력일이 대상이다. 60일 Brier는 보류로 60일까지의 정답이 불명인 6건을 제외한다. 주간 Brier도 정답을 확인할 수 있었던 기회의 점수이며 전체 추천 대상의 성능을 보장하지 않는다.

주지표는 Brier 점수다. 예측 확률과 실제 0/1 결과의 제곱 차이를 계산하고, 출발 구매 안의 평가 기회 → 고객 안의 출발 구매 → 고객 순으로 평균한다. 세 월의 기록을 합친 뒤 고객 평균을 계산한다. 월별 점수의 단순 평균은 별도 집계이며 선택에 사용하지 않는다. 평가 기회가 하나도 없는 출발 구매·고객은 해당 점수에서 제외한다. 낮을수록 좋다. 고객마다 동일 가중치를 주며, 전체 기회를 합친 Brier와 60일 내 재구매 Brier도 별도 표시한다. 후보 선택은 주지표로만 하며, 20%·35%·50% 문턱은 사전에 고정한 진단값이다. 운영 기준으로 승인된 값이 아니다.

문턱별 정밀도는 추천 기회 중 실제 7일 내 구매한 비율, 재현율은 실제 구매가 있는 평가 기회 중 추천한 비율이다. 같은 출발 구매가 여러 주의 평가 기회에 나타날 수 있으므로, 이 값은 중복을 제거한 실제 장바구니 성능이 아니다. 57~60일째 구매는 60일 평가에는 포함되지만 마지막 7일 창은 56일에 끝나므로 주간 평가 양성에 포함되지 않는다.

AFT의 날짜 출력은 무조건부 분포의 중앙값이다. 60일 너머 날짜는 검증되지 않은 외삽이다. KM에서 60일 안에 중앙값에 도달하지 않으면 CSV의 61은 ‘60일 초과’ 표시이며 정확한 날짜 예측이 아니다. KM의 해당 날짜 MAE를 성능 비교 근거로 사용하지 않는다. 확률 점수와 재구매자만의 날짜 MAE를 같은 목표로 해석하지 않는다.

## 실행과 산출물

```bash
python3 -m scripts.run_survival_experiment
```

`artifacts/survival-experiment-v1/`에 설정·입력 해시, 모델, 학습 곡선, 모든 예측, 확률 평가 기회, 집계 보고서를 저장한다. 기존 출력은 덮어쓰지 않는다. 고객 식별자를 포함한 예측 CSV는 로컬에만 남는다. 문서와 Grafana에는 집계만 사용한다.

최신 상태 스냅샷을 이용한 과거 실험이며 당시 주문 상태 가용성은 미검증이다. 기존 최종 시험을 확인한 뒤 진행한 개발 비교이므로 새 독립 시험 성능을 주장하지 않는다. 모델·확률 문턱의 실제 채택은 새로운 미래 로그에서 확인해야 한다. 앱 장바구니에는 아직 연결하지 않았다.

방법 근거: [XGBoost AFT 공식 문서](https://xgboost.readthedocs.io/en/stable/tutorials/aft_survival_analysis.html).
