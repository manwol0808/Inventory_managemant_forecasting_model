# 첫 학습 전 추가 전처리

2026-09-16. 상태·수량·구매일 연결은 구현했다. 아래는 사용자 요청에 따른 업무 제외 범위 보완안이다. 충전 상품·테스트 계정과 샘플·명시적 사은품 제외를 적용했으며 현재 산출물은 v4다. [적용 결과](evidence/preprocessing-applied-v4.md). 나머지 검토 항목은 아래 기준을 따른다.

| 항목 | 처리 방향 | 확인 또는 구현할 내용 |
|---|---|---|
| 내부 테스트 주문 | 이름이 정확히 테스트인 계정 1개 제외 적용 | 원본 조회로 회원코드 확인, 11행 모두 기존 취소. 이름 미확인 7명은 유지 |
| 샘플·명시적 사은품 | 첫 모델 자동 보충 대상에서 17개 코드 제외 적용 | 고정 상품코드 사용. 같은 주문의 정상 상품·고객의 다른 이력 유지. 일반 사은품 증정 행사는 일괄 제외하지 않음 |
| 만월플러스·임시개인결제창 | 충전 상품으로 확인되어 6개 코드 제외 적용 | 충전 구매와 실제 상품 구매를 구분. 같은 주문의 정상 상품은 유지 |

| 0원 결제 | 자동 제외하지 않음 | 정상적인 적립금·할인 구매인지 CSV만으로 확정 불가. 결제 수단이나 주문 목적이 확인될 때 판단 |

포장 상품은 현재 상품 코드의 주문 개수로 유지한다. 예를 들어 5개 묶음 상품 수량 2는 2묶음이며 10으로 바꾸지 않는다. 컵·빨대 같은 소모품, 직배송 상품, 할인 상품을 이름만 보고 일괄 제외하지 않는다. 같은 고객·상품의 짧은 재구매 간격도 실제 반복 구매일 수 있으므로 중복 주문으로 추정하지 않는다.

## 적용 전 영향 계산 기록

제외 적용 전 정답 13,587쌍을 기준으로 후보 상품 코드를 제외하는 영향을 계산했다. 고객별 테스트 주문 제외는 포함하지 않았다. 다음 수치는 서로 다른 상품 코드 집합으로 확인했다.

| 후보 | 상품 코드 수 | 빠지는 재구매 정답 쌍 |
|---|---:|---:|
| 샘플명 상품 | 15 | 113 |
| 명시적 사은품명 상품 | 2 | 173 |
| 만월플러스·임시개인결제창명 상품 | 6 | 381 |
| 합계 | 23 | 667 |

모두 제외한다고 가정하면 **12,920쌍이 남는다(4.9% 감소)**. 이 중에서 다시 시간순 학습·검증·시험을 나눠야 하므로 12,920개 전체가 학습 표본은 아니다. 후보 코드·이름·입출력 해시·집계는 [영향 계산](evidence/preprocessing-impact-preview.json)에 있다. 상품 의미가 확인되었다거나 내부 테스트가 제거되었다는 수치가 아니다.

이 계산은 후보 상품 코드의 시계열 전체를 추천·학습 범위에서 빼는 가정이다. 다른 상품의 구매 날짜나 같은 상품의 두 구매 사이 간격을 변경하지 않는다. 단일 테스트 주문 제외가 실제 간격·정답 연결에 미치는 영향은 식별정보를 받은 뒤 별도로 계산한다. 전체 계정 제외는 그 계정 전체가 테스트라는 확인이 있을 때만 적용하고, 정상 구매가 섞인 계정은 확인된 주문번호만 제외한다.

## 적용 순서

1. 확인된 제외 기준에 버전을 붙이고 회원코드·주문번호·상품코드·사유를 명시한다. 이름이나 비정상적으로 보이는 수량으로 내부 계정을 추정하지 않는다.
2. 원본은 유지하고 제외 행의 원본 번호와 사유를 보존한다. 테스트 구매는 정답뿐 아니라 과거 이력·집계 피처·평가에서도 제외한다. 추천 대상에서 제외한 상품 이력은 v1 모델 입력에서도 빼고, 추후 별도 피처로 사용할지는 다음 실험으로 남긴다.
3. 기존 정답 CSV만 잘라내지 않고, 제외 표시된 원본에서 상태 판정·구매일·정답을 새 버전으로 다시 만든다. 실제 구매가 아닌 것으로 확인한 테스트는 정상 구매 사이의 보류 장벽으로 남기지 않는다. 반품·진행 중 등 실제 구매 여부가 불명확한 보류 장벽과 구별한다.
4. 행 수·고객/상품 수·수량·정답 수 변화를 대사한다. 기존 파일과 새 파일을 덮어쓰지 않고 비교한다.
5. 과거 입력 정보, 예측 기준 시각과 시간순 학습·검증·시험 분할을 만든다. 최신 상태의 과거 가용성과 마지막 날 수집 완전성은 별도 해결해야 한다. 해결 전 실험은 사후 정제 탐색 실험으로만 표시한다.
6. 직전 수량·과거 구매 간격의 단순 예측을 기준으로 두고 XGBoost 첫 모델을 학습한다. 이력량·수량 규모별로 평가하며 가드레일 숫자는 최종 시험 결과를 보기 전에 고정한다.

내부 테스트·충전 상품과 샘플·명시적 사은품 제외를 모두 적용했다. 현재 정답은 12,920쌍이다. 대량 주문·구성 변경 의심 사례는 오류 근거가 확인되면 이후 버전에서 수정하며 현재 개수 기준 자료는 유지한다. 전처리를 무한정 늘리기보다 오류·비대상 데이터와 정상적인 희소·대량 구매를 구분하는 데 집중한다.
