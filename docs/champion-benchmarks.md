# 현재 챔피언과 모델 비교 화면

**2026-09-18 변경:** 사용자 결정으로 재구매 장바구니 챔피언을 `reorder-champion-v3`로 기록했다([상세와 간격별 담기 시점](reorder-champion-v1.md), [화면](http://127.0.0.1:3008/d/reorder-champion)). 담는 날 규칙은 기존(예측일 7일 전 이전 월요일) 그대로 두고, 수량을 매장 단위 장바구니 모델 값으로 바꾸고, 매장 주문 리듬 예측이 더 이르면 최대 7일 앞당기며, 간격 예측을 분위 0.4로 재학습하고, 그 짝의 과거 예측 오차만큼 담는 날을 당기는 보정(앞당김만, 한도 7일)을 넣었다. 검증 2026-01~06 12,229건에서 늦음 14.5%→7.9%, 담긴 뒤 21일 안 구매 57.4%→62.0%, 수량 정확 50.1%→58.5%로 모든 축에서 앞선다. 판단 기준은 예측 없이 구매 다음 월요일에 담는 순진한 규칙이며, 챔피언은 그보다 21일 안 적중 54.0%→62.0%로 약 8%p 앞선다. 담는 날을 앞당기는 규칙 25가지는 모두 적중을 못 올려 채택하지 않았다. 재학습은 라우터 구조가 아닌 단일 XGBoost 상한 추정이며, 분위 0.4는 검증셋을 보고 고른 값이다. 담기 전 주 단위 재예측은 세 가지로 구현해 모두 실패했다 — 피처가 전부 구매 시점 고정값이라 구매 사이에 새 정보가 없다. 아래 2026-09-17 기록은 그대로 둔다.

**2026-09-17 변경:** 사용자 요청으로 고객-품목 주기 유형 라우터 `multi-agent-router-v1`을 챔피언으로 올렸다([등록 파일](../config/champion.json) `champion-v2`, 묶음 `artifacts/router-champion-v1/`). 일정형은 XGBoost 25분위, 점점 짧아짐은 TabPFN 25분위, 나머지는 기존 `xgboost-short-v2`(기본 모델로 함께 등록)가 예측한다. 이 품목의 첫 구매에는 장바구니를 담지 않고, 에이전트 학습에서 2026-01~02를 제외했다. 선택 근거는 챔피언 검증 1,196건에서 일정형 118건 ±7일 81.4%→90.7%, 첫 구매 제외 1,043건 72.8%→74.0%다. 월별 90일 관찰(45일 재구매 18,333건)에서는 챔피언 방식 56.36%보다 낮은 56.04%였고 고른 기간·확인 기간 모두 낮았다. [라우터 구조](multi-agent-architecture.md).

배치 일정: `.venv/bin/python -m scripts.router_champion predict --as-of 2026-09-16T00:00:00+09:00 --output artifacts/<새 폴더>`. 단건 미리보기 CLI(`scripts.predict_replenishment`)는 과거 이력이 없어 라우팅할 수 없으므로 기본 모델 `xgboost-short-v2`를 쓴다. 실험 스크립트의 챔피언 대체 모델과 Grafana 화면도 기본 모델을 가리킨다. 이전 등록으로 되돌리려면 `config/champion.json`의 `base_model` 내용을 그대로 등록 파일로 쓰면 된다.

2026-09-16 사용자 요청으로 `xgboost-short-v2`를 현재 챔피언으로 지정했다. 기계 판독 기준은 [챔피언 등록 파일](../config/champion.json)이다. 모델·스키마·보고서 해시를 고정했으며 로컬 미리보기 CLI는 `--model`을 생략하면 이 등록 파일을 읽는다. 명시적 모델 인자는 실험용으로 유지한다.

챔피언은 사용자가 선택한 현재 기준 모델이라는 뜻이다. 서로 다른 평가 계약의 점수를 비교해서 모든 모델 중 최고로 입증했다는 뜻이 아니다. 실제 앱 연결이나 장바구니 자동 적용을 변경하지 않았다.

[Grafana 챔피언·벤치마크](http://127.0.0.1:3008/d/forecasting-benchmarks)에서 현재 모델과 저장된 모든 비교 계열을 확인할 수 있다. 기존 검증 1,196건, 사용 완료 시험 786건, 60일 관찰 34구성, 90일 전체 이력·고객군·반복 이력 비교, 생존분석 14구성, 인공 시나리오를 별도 구역으로 표시한다. 날짜 ±7일·수량 ±2개·날짜 MAE를 함께 보고, 확률 점수는 Brier로 따로 표시한다. 수량이 규칙 기반인 실험과 별도 모델인 실험을 구분했다.

챔피언은 반복 주기가 여러 번 관측된 사례만 학습하지 않았다. 학습 6,579건 중 예측 시점의 같은 상품 구매 이력이 1회 3,150건, 2회 1,451건, 3~5회 1,485건, 6회 이상 493건이다. 모든 학습 사례에는 이후 재구매 정답이 있지만, 입력 시점에는 간격이 없는 첫 구매 이력도 포함된다. 등록으로 모델을 재학습하지 않았다.

화면은 고객별 원본을 포함하지 않는 저장 집계다. [생성 스크립트](../scripts/build_benchmark_dashboard.py)를 `.venv/bin/python -m scripts.build_benchmark_dashboard`로 실행해 갱신한다. 다른 평가 구역 간 단일 종합 순위는 만들지 않는다. [집계 근거](evidence/benchmark-dashboard-v1.json), [규칙적 이력 후속 비교](evidence/regular-history-v1.md)를 함께 보존한다.
