# 현재 챔피언과 모델 비교 화면

2026-09-16 사용자 요청으로 `xgboost-short-v2`를 현재 챔피언으로 지정했다. 기계 판독 기준은 [챔피언 등록 파일](../config/champion.json)이다. 모델·스키마·보고서 해시를 고정했으며 로컬 미리보기 CLI는 `--model`을 생략하면 이 등록 파일을 읽는다. 명시적 모델 인자는 실험용으로 유지한다.

챔피언은 사용자가 선택한 현재 기준 모델이라는 뜻이다. 서로 다른 평가 계약의 점수를 비교해서 모든 모델 중 최고로 입증했다는 뜻이 아니다. 실제 앱 연결이나 장바구니 자동 적용을 변경하지 않았다.

[Grafana 챔피언·벤치마크](http://127.0.0.1:3008/d/forecasting-benchmarks)에서 현재 모델과 저장된 모든 비교 계열을 확인할 수 있다. 기존 검증 1,196건, 사용 완료 시험 786건, 60일 관찰 34구성, 90일 전체 이력·고객군·반복 이력 비교, 생존분석 14구성, 인공 시나리오를 별도 구역으로 표시한다. 날짜 ±7일·수량 ±2개·날짜 MAE를 함께 보고, 확률 점수는 Brier로 따로 표시한다. 수량이 규칙 기반인 실험과 별도 모델인 실험을 구분했다.

챔피언은 반복 주기가 여러 번 관측된 사례만 학습하지 않았다. 학습 6,579건 중 예측 시점의 같은 상품 구매 이력이 1회 3,150건, 2회 1,451건, 3~5회 1,485건, 6회 이상 493건이다. 모든 학습 사례에는 이후 재구매 정답이 있지만, 입력 시점에는 간격이 없는 첫 구매 이력도 포함된다. 등록으로 모델을 재학습하지 않았다.

화면은 고객별 원본을 포함하지 않는 저장 집계다. [생성 스크립트](../scripts/build_benchmark_dashboard.py)를 `.venv/bin/python -m scripts.build_benchmark_dashboard`로 실행해 갱신한다. 다른 평가 구역 간 단일 종합 순위는 만들지 않는다. [집계 근거](evidence/benchmark-dashboard-v1.json), [규칙적 이력 후속 비교](evidence/regular-history-v1.md)를 함께 보존한다.
